座・Navi セットアップ手順
MySQLインストール → データベース作成 → Eclipse実行確認まで

この手順を上から順番にやれば、データベース接続からEclipseでの動作確認まで一通り完了します。
完成しているコードは GitHub と eclipse-workspace\za-navi に用意済み、MySQL接続用ドライバ（jar）も eclipse-workspace\za-navi\WebContent\WEB-INF\lib\ に追加済みです。

STEP 1　MySQLをインストールする

  1. ブラウザで https://dev.mysql.com/downloads/installer/ にアクセスする
  2. 「MySQL Installer for Windows」をダウンロードする（容量の小さい Web 版でOK。会員登録は ページ下の「No thanks, just start my download.」から不要でダウンロードできる）
  3. ダウンロードしたインストーラーを実行する
  4. セットアップタイプは 「Developer Default」 を選択する
  5. 「Accounts and Roles」画面で rootユーザーのパスワード を設定する
    ★ここで設定したパスワードは絶対に忘れないようにメモしておく。 これが DBUtil.java の PASS に書く値になります（STEP 4で使用）。
  6. そのまま「Execute」を押してインストール・設定を完了させる

確認方法：スタートメニューの「MySQL 8.0 Command Line Client」を開き、設定したパスワードでログインできればOK。

STEP 2　データベースを作成し、テーブル＋データを一括投入する

使用するSQLファイルは用意済みです：C:\Users\shogo\za-navi\docs\db\za_navi_schema.sql

このファイル1つで「テーブル作成」と「初期データ投入（部署6件・座席180件・ユーザー200件）」が 同時に完了します。

  1. 「MySQL 8.0 Command Line Client」を開き、rootパスワードでログインする
  2. 以下を1行ずつ実行する（コピペ推奨）
DROP DATABASE IF EXISTS zaseki1;
CREATE DATABASE zaseki1;
USE zaseki1;
SOURCE C:/Users/shogo/za-navi/docs/db/za_navi_schema.sql;

確認のため、以下も実行してみる：

SHOW TABLES;
SELECT COUNT(*) FROM users;
SELECT COUNT(*) FROM seats;

departments / users / seats / reservations の4テーブルが表示され、 usersが200件・seatsが180件と出ればOKです。

データベース名は zaseki1 でOKです（CREATE DATABASE zaseki1; はそのまま使えます）。 ただしテーブルを作る部分は、以前ご自身で途中まで打ち込んでいた CREATE TABLE 文ではなく、 上記のように SOURCE ...za_navi_schema.sql; で修正済み・完成版のスキーマを読み込んでください （古い方には今回見つかったバグの原因になっていた制約がそのまま入っています）。

STEP 3　プロジェクトフォルダをEclipseに追加する

  1. Eclipseを起動する
  2. 「File」→「Import...」
  3. 「General」→「Existing Projects into Workspace」を選んで「Next」
  4. 「Select root directory」の「Browse...」で C:\Users\shogo\eclipse-workspace\za-navi を選択
  5. 一覧に出る「za-navi」にチェックを入れて「Finish」

すでに開いたことがある場合はこの手順は不要です。

STEP 4　データベース接続情報を書き込む　★今回のキモ

  1. プロジェクトエクスプローラーで za-navi → src → dao → DBUtil.java を開く
  2. 以下の3行を見つける
private static final String URL  = "jdbc:mysql://localhost:3306/zaseki1?useSSL=false&serverTimezone=Asia/Tokyo&characterEncoding=UTF-8";
private static final String USER = "root";
private static final String PASS = "your_password";

PASS の "your_password" の部分だけを、STEP 1で設定した実際のrootパスワードに書き換える：

private static final String PASS = "ここに自分で設定したパスワード";

URL と USER はそのままでOK（STEP 2で作ったデータベース名・ユーザー名と一致しています）。 書き換えたら Ctrl+S で保存。

STEP 5　MySQL接続用ドライバ（jar）の認識を確認する

  1. za-navi → WebContent → WEB-INF → lib に mysql-connector-j-8.4.0.jar があるか確認（追加済み）
  2. 念のため、プロジェクトを右クリック→「Properties」→「Java Build Path」→「Libraries」タブで一覧に出ているか確認
  3. 出ていなければプロジェクトを右クリック→「Refresh」(F5)、その後「Project」→「Clean...」を実行

STEP 6　Eclipseでサーバーを起動して動作確認する

  1. za-navi を右クリック→「Run As」→「Run on Server」
  2. 「Apache Tomcat v9.0」を選んで「Finish」
  3. ログイン画面が表示されればサーバー起動は成功
  4. ログインして以下が動けばデータベース接続も成功：
    • メニュー画面に「本日の予約」などDB由来の情報が表示される
    • 「行先登録」→「在宅」または「出張」でメモを登録してもエラーが出ない
    • 「予約確認」→キャンセルボタンを押してもエラーが出ない

うまくいかないときのチェックポイント

症状考えられる原因
ログイン画面すら出ないTomcatサーバーが起動していない（STEP 6を再確認）
画面は出るがログイン後すぐエラーDBUtil.javaのPASSが間違っている、またはMySQLが起動していない
「Unknown database 'zaseki1'」エラーSTEP 2のデータベース作成がうまくいっていない
「ClassNotFoundException: com.mysql.cj.jdbc.Driver」エラーjarが認識されていない（STEP 5を再確認、Cleanを実行）
在宅・出張のメモ／キャンセルでエラーSTEP 2を修正済みのza_navi_schema.sqlで実行したか確認（古いSQLを使っていないか）

エラーが出た場合は、画面に表示されたエラーメッセージをそのまま伝えてもらえれば一緒に解決できます。
