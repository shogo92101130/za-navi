# 座・Navi 研修ハンズオン手順書

研修当日、この手順を上から順番に実施すれば、座・Naviをローカル環境で動かせます。
コマンドやパスは、つまずきやすい箇所も含めてそのまま記載していますので、コピー＆ペーストで進めてください。

---

## 0. 事前に準備するもの

| 項目 | 内容 |
|---|---|
| Eclipse | Java EE 開発者向けパッケージ（Eclipse IDE for Enterprise Java and Web Developers） |
| Java | JDK 17 以上 |
| Tomcat | **Apache Tomcat 9.0系**（重要、理由は下記コラム参照） |
| プロジェクト一式 | `za-navi` フォルダ（このdocsフォルダの2つ上の階層） |

> ### コラム: なぜ Tomcat 9.0 系を使うのか
> Tomcat 10 以降は `jakarta.servlet.*` という新しい名前空間に変わっており、このアプリのコード（`javax.servlet.*` を使用）とは互換性がありません。
> 「サーブレットのクラスが見つからない」等のエラーを避けるため、**必ず Tomcat 9.0系**をダウンロードしてください。
> ダウンロード先: https://tomcat.apache.org/download-90.cgi （Windows用 zip 配布版を選択）

---

## 1. Tomcatを準備する

1. 上記サイトから `apache-tomcat-9.0.xxx-windows-x64.zip` をダウンロード
2. 好きな場所に展開する（例: `C:\tomcat\apache-tomcat-9.0.xxx`）
3. 展開したフォルダの中に `bin` `conf` `lib` ... が並んでいることを確認

---

## 2. Eclipseでプロジェクトを作る

1. Eclipse起動 → **File → New → Dynamic Web Project**
2. 以下を入力して「Next」を繰り返し、最後に「Finish」

   | 項目 | 設定値 |
   |------|--------|
   | Project name | `za-navi` |
   | Dynamic web module version | `4.0` |
   | Context root | `za-navi` |
   | Generate web.xml deployment descriptor | チェックを入れる |

3. もし「Target runtime」が未設定・Tomcatが選べない場合は、隣の **New Runtime...** ボタンから
   - **Apache → Apache Tomcat v9.0** を選択
   - 「Tomcat installation directory」に手順1で展開したフォルダのパスを指定
   - **Finish**

> ⚠️ ここでパスを正しく指定しないと、後で実行時に
> `エラー: メイン・クラスorg.apache.catalina.startup.Bootstrapを検出およびロードできませんでした` というエラーが出ます。
> その場合は **Window → Preferences → Server → Runtime Environments** から該当のTomcatを選び直し、`bin\bootstrap.jar` が実在するフォルダを正しく指定してください。

---

## 3. ファイルを配置する

作成したプロジェクトのフォルダ（ワークスペース内の `za-navi`）に、配布された `za-navi` フォルダの中身をコピーします。

| コピー元（配布物） | コピー先（Eclipseプロジェクト） |
|---|---|
| `src/main/java/control/` | `src/control/` |
| `src/main/java/model/` | `src/model/` |
| `src/main/java/dao/` | `src/dao/` |
| `src/main/java/entity/` | `src/entity/` |
| `src/main/webapp/css/` | `WebContent/css/` |
| `src/main/webapp/images/` | `WebContent/images/` |
| `src/main/webapp/index.jsp` | `WebContent/index.jsp` |
| `src/main/webapp/WEB-INF/` | `WebContent/WEB-INF/`（上書き） |

コピー後、Eclipseの「Project Explorer」で `za-navi` を選択して **F5（更新）** を押し、ファイルが反映されているか確認します。

> 💡 もしコピー後にプロジェクトが Project Explorer に出てこない場合は、
> **File → Open Projects from File System...** → ワークスペース内の `za-navi` フォルダを指定 → Finish
> でプロジェクトとして認識させてください。

---

## 4. 文字コードをUTF-8に統一する（文字化け防止）

日本語が文字化けしないよう、最初に以下を必ず確認・設定してください。

1. `za-navi` プロジェクトを右クリック → **Properties → Resource**
2. 「Text file encoding」が **Other: UTF-8** になっているか確認（なっていなければ変更して Apply and Close）
3. 念のため **Window → Preferences → General → Workspace** の「Text file encoding」もUTF-8になっているか確認

> 💡 もし途中でファイルをコピーし直した・新規作成した後に文字化けが出た場合は、
> **Project → Clean...** → `za-navi` を選択してクリーンビルドすると直ることが多いです。

---

## 5. Tomcatで起動する

1. `za-navi` プロジェクトを右クリック → **Run As → Run on Server**
2. 「Apache Tomcat v9.0」を選択して **Finish**
3. 画面下の「Console」に `Server startup in XXXX ms` と出れば起動成功

---

## 6. ブラウザで開く

```
http://localhost:8080/za-navi/ControlServlet?action=login
```

### デモアカウント

| ユーザーID | パスワード | 種別 |
|------------|------------|------|
| `user001`  | `pass001`  | 一般ユーザー（田中太郎） |
| `user002`  | `pass002`  | 一般ユーザー（鈴木花子） |
| `admin001` | `admin001` | 管理者（管理者山田） |

一般ユーザーでログインすると「行先登録・座席予約・予約確認・氏名検索・部門検索」、管理者でログインすると追加で「座席利用状況・代理予約・マスタ更新」が使えます。

## 7. うまく動かないときのチェックリスト

| 症状 | 確認すること |
|---|---|
| `Bootstrapを検出およびロードできませんでした` | Tomcatランタイムの「installation directory」が正しいフォルダ（`bin\bootstrap.jar` がある場所）を指しているか（手順2参照） |
| `JSPのクラスをコンパイルできません` | エラーメッセージに出ているJSPファイル名・行番号を確認し、該当箇所のJavaコードの文法（変数の宣言漏れなど）を確認 |
| 日本語が文字化けする | ① プロジェクトのText file encodingがUTF-8か（手順4）　② ブラウザのキャッシュが残っていないか（`Ctrl+Shift+R`で強制再読み込み） |
| ログインできない / メニューが出ない | `action=doLogin` でPOSTされているか、`dao/AccountsDAO.java` のモックデータにそのユーザーIDがあるか確認 |
| 画面に何も表示されない・真っ白 | EclipseのConsoleに赤文字のエラーが出ていないか確認し、スタックトレースの一番上の行（`原因` の部分）を読む |
