座・Navi　不具合修正・改善履歴書
試験要領書（06_試験要領書.pdf）の試験項目 T01〜T12 に対応した開発中の不具合・修正一覧
作成日：2026-06-11
対象リポジトリ：za-navi（DB接続版 / Tomcat 9 / Java 21 / MySQL zaseki1）
凡例：対応済み 修正してコミット済み 問題なし 確認の結果バグなし

1. 本書の目的

座・Naviの開発中、試験項目 T01〜T12 の各機能を確認・改修する過程で発見された不具合・改善点を、 「どのファイル・コードが原因だったか」「どんな症状が出たか」「どう直したか」の形で簡潔にまとめたもの。 試験要領書とあわせて、デグレード確認や類似不具合の再発防止に利用する。

T01　ログイン・ログアウト

状態症状原因（ファイル・処理）対応内容
対応済み 「管理者ログイン」フォームから一般社員のID/パスワードでログインすると、管理者メニューには入れないものの、そのまま一般メニューにログインできてしまっていた LoginLogic.java
doLogin()		 loginType=adminのとき account.getAdmin() != 1 なら「管理者権限がありません」エラーを表示してログイン拒否するチェックを追加
対応済み コンパイルエラー「res cannot be resolved」：ログイン成功後に画面遷移用のsendRedirectを呼べなかった LoginLogic.java
doLogin()		 メソッドのシグネチャをdoLogin(req, res)に変更しthrows IOExceptionを追加して修正
対応済み ログイン画面のデモ用ID/パスワード表示がDB移行前の形式（user001 / pass001）のままで、実際のDB（数値ID）と一致せずログインできなかった login.jsp デモ表示を一般ユーザー 1002 / pass1002、管理者 1001 / pass1001 に修正
