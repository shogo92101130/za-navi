座・Navi　不具合修正・改善履歴書
試験要領書（06_試験要領書.pdf）の試験項目 T01〜T12 に対応した開発中の不具合・修正一覧
作成日：2026-06-11
対象リポジトリ：za-navi（DB接続版 / Tomcat 9 / Java 21 / MySQL zaseki1）
凡例：対応済み 修正してコミット済み 撤回 一度実装したが指示により取り消し 問題なし 確認の結果バグなし

1. 本書の目的

座・Naviの開発中、試験項目 T01〜T12 の各機能を確認・改修する過程で発見された不具合・改善点を、 「どのファイル・コードが原因だったか」「どんな症状が出たか」「どう直したか」の形で簡潔にまとめたもの。 試験要領書とあわせて、デグレード確認や類似不具合の再発防止に利用する。

対応済み 参加者検索が氏名・部署のみで、社員IDによる絞り込みができなかった AdminReserveLogic.java 社員ID部分一致での絞り込みを追加

対応済み 拠点・フロア・エリアを選択してから座席マップ画像が表示されるまで、ありえないほどラグがあった（① まず社員ごとの予約チェック、② 次に使用中座席ごとの社員情報取得、の2つのN+1クエリが原因） AdminReserveLogic.java
showForm()		 ①その日の予約済みuserIdをresDAO.findByDate()で1回取得しSet判定に変更（社員ごとのfindActiveByUserAndDate()呼び出しを排除）
